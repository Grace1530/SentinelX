# SentinelX Datasets

This directory contains datasets used for development, training,
validation, and research experiments.

## Rules

- Document every dataset source.
- Record dataset version.
- Record license information.
- Record preprocessing steps.
- Do not commit sensitive data.
- Do not commit unnecessarily large generated files.

## Development Data

Small synthetic test data may be used during development.

Real model training will be performed using documented
cybersecurity datasets.
